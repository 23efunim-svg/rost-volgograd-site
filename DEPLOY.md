# Развёртывание на TimeWeb

Сайт статический: HTML, CSS, картинки плюс один PHP-файл для приёма заявок.
Никакой CMS, базы данных и админки. Правки вносятся в `data/*.json`,
после чего запускается сборка.

## 1. Собрать

```bash
python build.py
```

Результат складывается в `dist/`. Внутри уже лежат `.htaccess`, `api/lead.php`,
`robots.txt`, `sitemap.xml` и все ассеты. Заливать нужно **содержимое** `dist/`,
а не саму папку.

## 2. Куда заливать

В панели TimeWeb у сайта есть корневая директория вида
`/home/<логин>/rem-opt-stroy-torg.ru/public_html/`.
Содержимое `dist/` кладётся туда целиком, поверх существующего.

Загрузка по FTP или через файловый менеджер панели. Для FTP нужен
**отдельный FTP-аккаунт**: логин панели управления к FTP не подходит,
аккаунт создаётся в разделе «FTP» панели.

## 3. Настроить почту для заявок

Форма работает по такой схеме:

1. Заявка пишется в `leads.csv` в корне сайта (страховка, если почта не дошла).
2. Пользователю сразу отдаётся ответ, письмо отправляется уже после этого,
   чтобы форма не «висела» на медленном sendmail.
3. Письмо уходит через авторизованный SMTP ящика компании. Без авторизации
   письма с виртуального хостинга обычно попадают в спам.

Создайте файл `smtp.php` **на уровень выше корня сайта** (рядом с `public_html`,
а не внутри него), чтобы он не отдавался по HTTP:

```php
<?php
return [
    'host'   => 'smtp.yandex.ru',
    'port'   => 465,
    'secure' => 'ssl',
    'user'   => 'REMOPTSTROYTORG@yandex.ru',
    'pass'   => 'пароль_приложения_из_яндекс_почты',
];
```

Пароль берётся не обычный, а **пароль приложения**: Яндекс ID → Безопасность →
Пароли приложений → Почта. Обычный пароль от ящика SMTP не пропустит.

Если файла нет, заявки всё равно сохраняются в `leads.csv`, а письмо уходит
через `mail()` и может попасть в спам. Первое письмо после настройки нужно
найти в папке «Спам» и перенести в «Входящие», чтобы обучить фильтр.

## 4. Проверить после заливки

```bash
curl -I https://rem-opt-stroy-torg.ru/                 # 200 и HTTPS
curl -s https://rem-opt-stroy-torg.ru/ | grep -c "Ремонт"   # страница отдаётся
curl -s -o /dev/null -w "%{http_code}\n" https://rem-opt-stroy-torg.ru/sitemap.xml
```

Затем отправить тестовую заявку с телефоном и убедиться, что:

- в браузере появилось сообщение «Заявка ушла»;
- в `leads.csv` добавилась строка;
- письмо пришло на `REMOPTSTROYTORG@yandex.ru` (проверить и папку «Спам»).

Одиночный «Empty reply from server» у TimeWeb это флап, повторите запрос,
прежде чем что-то чинить.

## 5. Что сделать в первые дни после запуска

1. **Яндекс Метрика.** Завести счётчик на аккаунт компании, вписать его номер
   в `data/site.json` → `analytics.yandex_metrika`, пересобрать и залить.
   Код счётчика загружается только после согласия в cookie-баннере.
2. **Яндекс Вебмастер.** Добавить сайт, подтвердить права, отправить
   `sitemap.xml`, задать регион «Волгоград».
3. **Уведомление в Роскомнадзор** о начале обработки персональных данных через
   `pd.rkn.gov.ru`. Форма на сайте собирает имя и телефон, уведомление обязательно.
4. **Карточки организации:** Яндекс Бизнес и Карты, 2ГИС. Название, адрес,
   телефоны и график должны совпадать с сайтом слово в слово, иначе
   поисковик считает данные противоречивыми.
5. **Поправить адрес в сообществе ВКонтакте:** там улица написана как
   «Цолковского», из-за одной буквы адрес не привязывается к картам.

## 6. Обновление сайта

```bash
git pull
# правки в data/*.json
python build.py
# залить содержимое dist/
```

Старый сайт на WordPress трогать не нужно: новый ставится на его место
одним копированием файлов. Перед заливкой имеет смысл сохранить копию
текущего содержимого `public_html`.

# Сайт РОСТ · РЕМОПТСТРОЙТОРГ (Волгоград)

Статический сайт строительно-ремонтной компании и базы стройматериалов.
Собирается генератором на Python + Jinja2, разворачивается на любой обычный
хостинг с PHP (боевая площадка — TimeWeb, домен `rem-opt-stroy-torg.ru`).

## Что внутри

| Путь | Что это |
|---|---|
| `data/*.json` | Все тексты, цены, контакты, каталог, портфолио. Правится без вёрстки |
| `templates/*.j2` | Шаблоны страниц (Jinja2) |
| `assets/` | CSS, JS, шрифты, логотип, обработанные фотографии объектов |
| `server/` | `.htaccess` и PHP-обработчик формы, копируется в корень сборки |
| `tools/` | Скрипты подготовки: конвертация HEIC, цветокор фото, трассировка логотипа, обложка |
| `build.py` | Сборка сайта в `dist/` |

## Сборка

```bash
python build.py          # собирает 44 страницы в dist/
python -m http.server 8099 --directory dist   # локальный просмотр
```

## Правила проекта

- **Ни одной выдуманной цифры.** Каждый факт на сайте берётся из документов клиента,
  источник указан в поле `_источник` или `_src` соответствующего JSON.
- Формулировки «самый», «лучший», «дешевле всех» запрещены: реклама с превосходной
  степенью без объективного критерия нарушает ФЗ-38 «О рекламе».
- Формулировка «без задержек» не используется: клиент её не подтвердил.
- Калькуляторы считают по открытым формулам и показывают цифру сразу,
  без «оставьте телефон, посчитаем».
